# Capri Downloads

Public download area for Capri, an experimental Android AI companion.

## Current test build

**Capri 0.6.2 RC2** (Android, app ID `app.capri.companion.candidate`, version code 10).

The APK is a test candidate, not a certified release. Voice, microphone, overlays and device-specific behavior still need testing on real phones.

### Installing on Android

1. Download `Capri-0.6.2-rc2-candidate.apk` from this repository when available.
2. Open the APK from Downloads / My Files.
3. If Android asks, temporarily allow installations from your file manager or browser.
4. Install it. If you already have v0.6.1 RC2 with the same signing certificate, use **Update**. Do not uninstall the older app or clear its data.
5. Open Capri, grant only the permissions required for features you want to test, and configure your own AI API key if you use a cloud brain.

**Privacy:** Testers should use their own accounts/API credentials. No API keys or existing chat histories are bundled for testers. Don't send keys to others.
